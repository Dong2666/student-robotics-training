## What I Learned

- entry_points in setup.py is the bridge between a Python function and
  a ros2 run command
- setup.cfg decides where installed scripts land; without it ros2 run
  cannot find the executable
- An empty-workspace build validates the toolchain before any real code
  exists
- Quoting through multiple shells silently rewrites commands — prefer
  passing a script file instead of inline one-liners
